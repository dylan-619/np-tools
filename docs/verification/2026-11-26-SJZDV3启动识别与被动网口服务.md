# SJZDV3 启动识别与被动网口服务配套验证

日期：2026-11-26；分支 `main`，本记录覆盖本次 SJZDV3 配套修改，未安装为原生桌面发行版。

- 星闪、4G、Netty 保留为三种可选主动上报协议；NONE 表示关闭或未选择主动上报。默认 Modbus TCP 不要求选择 Netty。
- 网口页增加“仅使用 Modbus TCP（关闭主动上报）”操作，下发 `WLAN_TYPE:LOCAL`，写后重启核对保存字节 254、NONE/SAVED、UART2 停用及网络保存值/运行值。关闭 Netty、开启 Modbus TCP，并保留 IP、端口、AI Unit、目标和采集点表；无需无线应答，模块仍插着也不再探测。缺少新能力字段的旧固件禁止此操作并提示升级。
- 兼容新的 NONE/NETTY 模式读回、AUTO_PROBING/AUTO 来源和独立模块 UART 状态，同时兼容旧固件的字段缺失与 Netty 承载回显。
- Netty 显式切换检查重启、保存字节、UART 停用和原网络配置；无模块自动结果只读取状态，不发送 Netty 选择或 NET 写入。无线停用或自动探测期间禁止透传及无效 4G 重连。
- 网口、概览、星闪、4G 和串口命令页同步显示与提示；F411 保持不支持网络配置的限制。
- `pnpm build` 通过；`pnpm test:protocol` 共 9 组 165 项全部通过。新增覆盖保存过 SLE/4G/Netty、模块无应答时切回被动服务，以及旧固件能力拒绝。
- 使用真实 Vue/Pinia Store 源码，经本地桥接将 Tauri 串口发送接到目标板 UART1，完成两次 SLE→LOCAL→重启、重新启用 SLE、显式 Netty 及关闭恢复的实板协议联调。板上星闪模块保持安装，SLE 有实际应答；LOCAL 读回 NONE/SAVED/254、UART2 停用，Modbus TCP 1502、AI Unit 246 保留。此方式验证 Store 与实际固件的事务，不等同原生桌面点击验收或安装新发行版。
- 固件实板 Modbus TCP 连续读取、自动识别及 ET703 实物从站结果见联合记录；真实拔插和 4G 实物未覆盖。
