# SJZDV3 AI250 与标准端口配套验证

日期：2026-11-26。用户指定本机 AI 统一使用 TCP Unit ID 250，实板恢复标准端口 502，固件显示 SJZD_V4.0.0。

- 网络配置默认 AI250，保存与回读支持 TCP 非零一字节 ID（1～255）；网络页提示、重置说明和表单边界同步。
- 通用 Modbus 调试按传输区分地址范围：TCP 1～255，RTU 仍为 1～247。SJZDV3 AI 入口允许预填 250，保持临时配置隔离；Rust TCP 客户端不再将合法虚拟单元 250 拒绝为串行地址超限。
- `pnpm build`、9 组 167 项协议/组件测试通过；Rust TCP 的 4 项测试通过，含 Unit250 / FC04 的本地 socket 事务。
- 使用真实 Store 经物理 UART1 将该板 246/1502 改为 250/502，保存和重启读回均通过；IP、其他网参和 ET703 21 点保持。设备后续双客户端连续读取通过。
- 已生成 `target/NP-Tools-SJZD-AI250/NP-Tools.app` 及 ZIP 本机调试包，并完成 ad-hoc 签名校验；桌面基础版本仍为 1.1.3，没有替换已安装应用。构建基于已提交源码加本次实现文件，未纳入无关 KZ3 工作区改动。未进行原生窗口点击验收。

当前 HMI 使用 **192.168.30.55:502**；AI 用 **250 / FC04 / PDU 0、2**，电表用 **3 / FC03 / 原始地址**。Modbus TCP 独立于主动上报选择，SLE/4G/Netty 模式下仍可使用。

完整日志、实板报文和产物哈希见 [联合记录](../../../SJZDV3/docs/verification/2026-11-26-V4.0.0与AI250统一验证.md)。
