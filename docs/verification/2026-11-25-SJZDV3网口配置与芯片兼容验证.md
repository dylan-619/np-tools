## 1. 功能与回显边界

| 项目 | 实现行为 |
| --- | --- |
| F411 | 设备信息页、网络页共享本次连接的芯片选择；F411 禁用专用网络入口、表单和 NET 操作，保留其他设备功能 |
| F412 / 未知 | F412 仍核对固件支持；未知允许只读 NET 探测，完整快照成功后标记协议确认。旧固件明确不支持时禁止写入 |
| 设备切换 | 串口变化或读取到不同 SN 后，清除旧网络能力、快照、状态和验证标记；不根据 SN、产品编码或烧录页选择猜测芯片 |
| 默认与关闭 | 无效/空白 EEPROM 显示记录原因及 RAM 回退值 `.55:502 / AI247 / flags=2`；合法已保存的关闭值优先。读取失败不自动写默认值 |
| 参数与保存 | 校验 IPv4、连续掩码、网关、目标端口、四种 flags；保存前读完整 485 点表检查 AI 冲突。只发一条完整 SET，核对回执 hash/revision 和完整 LIST 字段 |
| 三列回显 | 分列显示本地编辑、SAVED 和 RUNNING；保存后运行值未变显示待重启。刷新不覆盖未保存草稿；失败保留历史值并禁止写入 |
| 重启 | 独立确认后只发一次重启，观察启动日志、核对 SN、实际字段与 pending_restart。串口断开取消事务，需手动重连再读，不自动重发 |
| 状态 | 收齐 STATUS/NETTY/MODBUS/CACHE/RESOURCES 五类行，缺项保持未知，实际 0 保留 0；状态不作为配置保存证明 |
| 承载 | 分离无线选择、原始保存字节和实际 NETTY/SLE/4G 承载；Netty 下禁止 UART2 透传和 4G 重连；切回无线核对 SWITCH 和重启后读回 |
| AI 调试 | 使用 STATUS 实际 IP、RUNNING 端口/Unit 预填两路 FC04、PDU 0/2、FLOAT32 ABCD；不自动读取，不覆盖通用工作台原有持久化配置 |

操作步骤见 [配套说明](../SJZDV3网口配置与ModbusTCP调试说明.md)。

## 3. F412 实板 Store 串口集成

设备 UART1：`/dev/cu.usbmodem1203`，115200 8N1，SN `430126070777`。验证直接加载本次实际 Store 和 NET 解析器，仅将 Tauri IPC 传输替换为独占物理 UART1 的桥接；设备响应、EEPROM 写入、重启及 TCP 读取均来自真实板卡，未模拟串口回包。

| 阶段 | SAVED | RUNNING | 复核结果 |
| --- | --- | --- | --- |
| 初始 | `.55:502 / AI247 / flags=2` | 相同 | 完整配置、承载与五类状态通过 |
| 保存自定义参数 | `.55:1502 / AI246 / flags=2` | 仍为 `.55:502 / AI247` | 回执和 LIST 一致，pending_restart=YES，未提前标记运行生效 |
| 显式重启 | `.55:1502 / AI246` | 相同 | 观察启动日志、同 SN、pending_restart=NO；真实 TCP 端口1502 / Unit246 / FC04 读取成功 |
| 恢复并重启 | `.55:502 / AI247 / flags=2` | 相同 | 再次观察重启并完整读回；真实 TCP 502 / Unit247 读取成功 |

本次 TCP 读到 AI1/AI2 均为 0mA，原始响应保留在结果 JSON；这项仅确认运行端口、Unit 和读取路径，不是电流精度验收。没有操作其他 EEPROM 区域、无线参数或 485 点表。

首次脚本在重启后立即绑定主机源地址时失败，恢复流程仍完成默认配置读回。确认 PHY 重启后主机地址/路由短暂恢复等待，加入有限次数的链路等待后全流程通过；没有修改电脑网卡设置。最终 Modbus 开启、Netty 关闭、实际上报 SLE，UART1 已释放。之后补充的写前身份校验、失效标记、资源字段显示和 F411 旧无线日志兼容由最终自动化回归覆盖，未重跑整轮物理写入。
