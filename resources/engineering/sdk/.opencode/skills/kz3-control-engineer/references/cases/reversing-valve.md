# C04 双向阀/闸门参考

状态：按现有计时契约生成的状态机设计参考，不是 T02 的等价包装。
[双向保护契约](../control-timing-contract.md#阀门双向反转保护) 是实现约束。
开/关 DO 与开/关到位 DI 分别映射，核对保持/脉冲、到位撤输出、安全动作、反馈质量与行程时限。
双到位同时有效如何处理须按设备语义确认，不当成两个方向电机都停。

每阀保存方向、最近实际输出方向、全断起点、独立停止记录、行程计时与故障；历史不能被模式/复位绕过。

| 输入/状态 | 必须行为 |
| --- | --- |
| 手动正在开时直接发关 | 拒绝本次关令，不锁存待执行；开方向后续按原有效请求/STOP/保护处理 |
| 独立 STOP | 双 DO 撤销，实际转为全断时记起点；重复 STOP 不反复推迟起点 |
| STOP 后不足 2000 ms 发反向 | 拒绝且不排队；到 2000 ms 不自动执行 |
| 全断满 2000 ms 后新反向命令 | 重新核对许可、反馈、故障和互斥，合法才执行 |
| 自动需要反向 | 先全断，至少 2000 ms 后重判当时工艺条件，取消条件则不动作 |
| 模式/复位/控制器停启 | 撤掉过期请求；保留或保守重建完整死区，不因此直接允许换向 |

只有实际施加方向输出后才启动该方向行程监督；等待死区不消耗行程时间。保护优先，输出永不同时为真。
测试双方向的未停止、1999/2000/2001 ms、新命令、早令后静候、条件撤销、坏质量、双命令、
到位/超时、复位/模式切换绕过、tick 回绕。不得将“已等一拍”当作 2 s。

## 可直接参考的 C 保护器

随包提供 [valve_reverse_guard.h](../../assets/control-templates/valve_reverse_guard.h)，源自 KZ3 公共保护器。
它是最终方向请求门控，不是完整阀控制器，不包含物理点绑定、许可/故障或到位行程监督。
使用 `ValveReverseGuard_Step(&memory, &off_since_ms, &input)`；两个 u32 必须来自项目 context state。
每扫描每实例只调用一次，`minimum_off_ms` 传 `VALVE_REVERSE_MINIMUM_OFF_MS` 或冻结的更长值，
调用者明确禁止小于 2000 ms；源码内部仅检查非零与回绕范围，不代替此产品下限检查。
`discard_manual` 为 true 时调用者必须清除本次手动动作目标，否则不满足“早令不排队”。
`waiting` 时不运行行程监督，`started` 为 true 时才记实际动作起点；自动等待结束前重算条件。
停止生命周期使用 `ValveReverseGuard_Off` 记录全断，不清历史；不可用 Init/Reset 强行绕过等待。
不得传空指针；最终保护撤销也须反馈到保护器的全断记录。保护器只证明软件请求互斥和间隔。
