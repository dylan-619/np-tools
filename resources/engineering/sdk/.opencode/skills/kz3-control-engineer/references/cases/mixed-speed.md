# C02 固定变频主调 + 工频辅泵

状态：组合设计参考；来源 [W09](../water-process-boundaries/09_mixed_speed_group.md)。
P1/P2 只是角色示意，不携带端子或参数。需要 C01 时先组合 C01。

主调池仅含有调速能力的设备，工频池只有启停能力；轮换只能发生在可互换池。
不得把“所有泵按运行小时轮换”解释成工频泵接替唯一变频泵的 PID 调速能力。
一变频器切换多电机须另有接触器、互锁、断电切换/停稳依据；本卡不生成该拓扑。

| 转移 | 必须先具备 | 请求/完成规则 |
| --- | --- | --- |
| n → n+1 | 压力不足且实际满频条件连续成立；有可用工频自动候选及容量 | 单次投入一个候选，真实运行后提交级别，重建确认窗口 |
| n → n−1 | 低负荷减级条件连续成立，满足最小运行时间 | 选定工频设备停止，真实停止后释放容量，PID 按冻结跟踪处理 |
| 主调失效 | 主调故障或质量/许可失效 | 默认不擅自工频降级；在需求阶段确认停相关自动或独立降级表 |
| 辅泵故障 | 撤该泵请求，确认实际运行/未知状态仍占容量 | 有允许容量才替补，不因 DO 已撤就认定停稳 |

工艺阈值、满频来源、每级上下行、等号、持续时间、最小启停、最大台数、故障降级均逐条冻结。
没有频率反馈时不可用 AO 请求值假冒实际满频；可提出只用压力的替代判据，但须明确采纳。
调度结构：
```text
occupied = count_distinct(running OR starting OR stopping_unconfirmed OR unknown)
if pending_transition:
    wait_for_feedback_or_abort()  # 不在同拍再发一个投退泵动作
elif confirmed_add and occupied < capacity_limit:
    select_one_eligible_fixed_speed_pump()
elif confirmed_remove:
    select_one_eligible_running_fixed_speed_pump()
```
手动/就地设备不能被自动命令，但其实际运行计入容量。按真实累计均衡时 T05 提供秒数，平局稳定按编号；
不为了追平时长在同级频繁轮换。STOP 后是否重新入池必须明确，不能下一拍又自动拉起。
验收：同时到时仅一次变更、候选不足、满频质量坏、手动占容量、停机粘连、唯一变频失效、两台相同累计、
参数在线变化中止/延续规则及上下行各级边界。分级算法是本项目定制组合，不能以 T01 单体通过替代。
