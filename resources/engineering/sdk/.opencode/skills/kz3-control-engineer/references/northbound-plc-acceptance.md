# 北向 PLC/HMI 使用验收

短名白名单是接口约束，不是删掉操作诊断的理由。以每个实际设备和仪表的使用任务核对以下内容，
不适用项注明原因；地址/宽度/类型/访问/单位/范围/枚举及质量策略均交付给 HMI。

- 电机：远程/就地反馈、模式设定及当前有效模式、启动/停止/复位、真实运行、DO 输出、
  总故障及可见分项、可用/禁止原因、真实反馈累计秒数及独立清零；没有 RUN 不伪造运行或累计。
- 自动：逐台模式选择；运行/停止时长、相关阈值及延停设定；影响操作的暂停、依赖未就绪和配置未就绪。
  内部时间戳/边沿记忆不发布；操作员需要判断的“暂停/禁止原因”可以且应当发布。
- 仪表：工程值、工程单位、量程上下限、工艺实际需要的报警上下限和报警状态、测量质量/数据有效性。
  单侧报警可以只提供对应一侧，但需求中应说明其工艺依据，不能机械添加或漏掉要求。
- 保持旧 PV 的宽限期：HMI 必须可见原始测量已经失效/值为保持值，以及控制是否暂可使用。
  `控制允许暂用旧值` 不等于 `当前测量 GOOD`。禁止只报 GOOD+valid=true 而隐藏采样失效。
- 外部状态：实时值与失效/就绪诊断；首次接收前 INIT 不可用，同值更新刷新时效；恢复策略可查。

复用 `northbound-contract.md` 的唯一短名；新增业务语义先扩展本项目冻结映射并说明，不能临时造同义词。
操作模式可以是一个带枚举含义的 MODE 参数，不要求再增加冗余 AUTO 开关。

当前平台接口能力须以目标版本验证。已核对的基线只保证单字段写入（一个 float 的两个寄存器是一字段），
不能依赖多字段批量原子写入或一包多线圈。整组参数逐字段写时所有中间组合都须校验；合法中间组合
是否立即生效由冻结策略决定，需要完整事务就设计禁用/应用步骤或明确列平台扩展，不能假装已有事务。
多字段读也不能未经证据声称一致快照。协议 ACK 只说明写入请求结果，不代表设备动作或 EEPROM 完成。
操作成功用真实反馈判断；拒绝/超时通过状态和故障展示，不能把 DO=1 显示成设备已运行。
