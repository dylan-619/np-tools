# W06_AERATION · 曝气风机与溶氧/压力控制

状态：reference_boundary；PLC 需求边界参考，非认证模板、非可运行项目。

## 原始输入形状与适用判据

PLC 初步需求示例：“风机轮换，按时段或溶氧调节；可能按总管压力控制风机、池内溶氧调阀。”

点位证据：风机就绪/运行/故障、启停及速度接口；DO 溶氧仪、压力、风量或阀位按原方案；这里 DO 测量含义与数字输出须明确区分。

匹配条件：区分定时曝气、直接溶氧调风机、溶氧调阀+总管压力调风机、厂家群控。点表有溶氧仪也可能只用于监控。

必须保留：保留 PLC 的回路划分、供气对象、轮换方式和最低工艺需求；沉砂池罗茨风机启停联动不能当作生化池溶氧闭环。
