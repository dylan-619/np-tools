# W02_SCREEN_PRESS · 格栅、压榨机与输送联动

状态：reference_boundary；PLC 需求边界参考，非认证模板、非可运行项目。

## 原始输入形状与适用判据

PLC 初步需求示例：“液位差优先、定时间歇辅助；任一格栅启动时压榨机同步启动，全部格栅停止后延时停压榨机。”

点位证据：每机远程、运行、故障与启停；独立液位差计或 PLC 明定的差值来源。绝对液位与气体监测点的用途单列。

匹配条件：适用于多个上游共享一个下游。自动联动不扩展到手动；未明说手动联动时，各设备默认独立
手动并整组确认一次。不能套互斥主备。

必须保留：原文明定同步请求就保留同步；下游先运行确认是工艺变更建议，不自动替换。手动默认独立，
只有 PLC 初步需求明文或用户确认的特殊手动联动才跨设备动作。

## 逻辑关系参考

以下是补全后可审查的关系，变量均为概念，不代表现有 C API；仅执行已确认分支。
联动延停变体与反例见 [F08](../field-control-patterns.md) 和 [计时契约](../control-timing-contract.md)。

```text
各格栅按已确认仲裁形成上游请求 → 计算下游目标
按同步/下游先行变体决定上游输出许可 → 各设备监督
最后上游真实停止 → 有界清料 → 停下游；新请求/故障走各自分支
```
