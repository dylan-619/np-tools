# W03_MIXER · 调节池与均质池搅拌机

状态：reference_boundary；PLC 需求边界参考，非认证模板、非可运行项目。

## 原始输入形状与适用判据

PLC 初步需求示例：“支持远程手动；自动运行一段时间、停止一段时间，周期参数可调。”

点位证据：远程、运行、故障、启停；液位或淹没许可仅在 PLC 要求且点表存在时使用。

匹配条件：适用于连续/间歇搅拌。设备编号“1-4”不能自动解释成四台，先由点位与描述确定数量。

必须保留：保留连续/间歇模式、现有周期和首次进入自动的阶段；不因为池名自动添加低液位联锁。
