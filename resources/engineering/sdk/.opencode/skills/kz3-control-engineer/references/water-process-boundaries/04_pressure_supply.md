# W04_PRESSURE_SUPPLY · 恒压供水与变频泵组

状态：reference_boundary；PLC 需求边界参考，非认证模板、非可运行项目。

## 原始输入形状与适用判据

PLC 初步需求示例：“按出口压力调速，压力不足加泵、需求减少减泵，轮换运行。”

点位证据：压力、每泵运行/故障/远程、转速命令与必要反馈、水源/吸入侧许可；变频通信、AO 或成套控制器接口须按原点表识别。

匹配条件：先辨别每泵独立变频、一变频多工频切换、或成套柜内部级联。仅有成套柜启停/设定接口时，不能由 KZ3 再做第二套 PID/加减泵。

必须保留：保留 PLC 指定的 PID owner、泵/变频器连接拓扑、允许并行和压力目标；压力 PID 功能测试参数不能用于供水整定。

## 逻辑关系参考

以下是补全后可审查的关系，变量均为概念，不代表现有 C API；仅执行已确认分支。

```text
压力/水源许可/参数检查 → 由已指定 owner 调节

每机监督 + 超压/缺水处理；切换时维持约定 PID 跟踪
```
