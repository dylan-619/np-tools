# W05_THERMAL_LOOP · 冷热水循环与换热机组接口

状态：reference_boundary；PLC 需求边界参考，非认证模板、非可运行项目。

## 原始输入形状与适用判据

PLC 初步需求示例：“循环泵主备，按温度或压差运行；满足条件后允许冷机/热源，停机后循环延时。”

点位证据：循环泵运行/故障/远程、流量/压差证明、温度、调节阀、冷/热源允许与状态，按原方案选用；无源设备接口时不新增输出。

匹配条件：区分只控制循环泵、换热阀控制、与厂家成套冷/热源联动三种范围。一次侧/二次侧、供水/回水不可凭点名互换。

必须保留：保留 PLC 的调节对象、传感器位置、泵主备/并联规则和厂家控制边界；KZ3 不接管机组内部压缩机/燃烧控制。

## 逻辑关系参考

以下是补全后可审查的关系，变量均为概念，不代表现有 C API；仅执行已确认分支。

```text
按既定模式校验水路 → 启泵/证明流量 → 开放冷/热源允许
原调节 owner 处理温度/压差；正常停源后按确认顺序退出
断流或异常 → 对源/泵分别执行已确认故障矩阵
```
