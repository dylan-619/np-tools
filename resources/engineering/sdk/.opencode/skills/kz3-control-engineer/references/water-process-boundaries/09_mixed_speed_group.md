# W09_MIXED_SPEED_GROUP · 固定变频主调与工频辅调

状态：reference_boundary；需求边界组合卡，非认证实现、非现场参数集。与 W01 排水/提升或 W04 供水
组合使用；先依据原文确定作用方向。只有明确具有变频调速接口的设备才进入变频能力池。

## 适用判断与三组建议

适用于部分泵可连续调速、其他泵只启停的分级组。每泵独立变频、一台变频器切多台电机、厂家柜内部
级联不是同一变体。没有变频切换接触器点位不能生成变频器跨泵切换。

通常把缺口组织为：D01 调速归属与接口；D02 台数/升降级/轮换；D03 故障降级/质量丢失/恢复。
已有明确项不重问；每张卡的改变和风险都写明。以下只提供选择依据，不自动采纳。

| 边界 | 首选补全方法 | 必须排除的错误 |
| --- | --- | --- |
| W09_B01 闭环控制者 | 列出 PV 到谁、SP 到谁、AO 表示频率还是目标、变频器模式。按原方案只保留一个 PID；点表与原文矛盾时提出最小修订供选 | 用 KZ3 AO 频率接口就断言厂家 PID 已关闭；或同时运行两套 PID |
| W09_B02 能力池/容量 | 区分固定变频池与工频池，明确最大总台数/功率及备用角色。例如 1+4 而原文最高 4 台，可建议 1+3 与动态备用，但不能直接认定 | 最短运行时选中不具备变频能力的泵；默认最后编号永远备用；编造额外级别 |
| W09_B03 升降级 | 每级分别列上升、下降、等号、滞回、连续确认、执行完成、下一次允许时刻。满频与高位联合确认；普通转换默认 30 秒 | 只有上升表；多个计时同时到期一拍连投；把“持续高位”偷偷等同“严格上涨” |
| W09_B04 均衡 | 仅在可互换池内排序；最短时先启/最长时先停按真实累计，平局稳定按编号；同级不为追赶时长频繁换泵 | 后进先出与最长时先停混用；按输出累计冒充真实运行 |
| W09_B05 混合模式 | 就地/手动实际运行、启动待确认、停机未确认及质量未知占容量，逐设备去重。自动不得接管无控制权设备；停止后的重新入组条件明确 | 手动旁路容量；未停稳却释放名额；STOP 后下一拍自动重选 |
| W09_B06 故障替补 | 先撤故障请求，再按拓扑和剩余容量判断替补；互斥需要停稳/死区，并联不强制全组停。停止粘连或未知仍占容量 | 故障撤 DO 就当物理停止；第五台无条件补入；所有泵套互斥模板 |
| W09_B07 异构降级 | 唯一变频泵失效时明确“停止相关自动”或“批准的工频分级降级”；后者另列台数/阈值/速度能力/进入退出条件，并取消不再存在的满频前提 | 把工频备用描述为等价恒液位能力；默认允许降级；进入降级突然补满全部泵 |
| W09_B08 测量与通信 | 液位、实际频率和各设备质量分别确定影响范围。频率坏质量不能当满频；扩展模块丢失不能当其泵已停；全停可能溢流/断供，给风险与可用替代 | 使用旧频率放行加级；凭空增加备用液位开关；恢复自动消除锁存 |

## 时间、参数与调节协同

- 给出相邻级转换表及普通总停阈值。是否直接总停、逐级减、阈值共用都要唯一；案例不替工艺选液位。
- “满负荷仍上涨”拆成满频判据与液位判据。推荐持续超阈值代替趋势时必须标为原文修订；确需趋势则
  冻结观察窗口、变化量、噪声/质量和恢复处理。频率给定值不替代实际频率反馈。
- 普通阈值连续确认、最小运行/停机、启动间隔、反馈超时、PID 周期与通信时效是不同时间。
  相关参数任何变化均取消该转换旧确认；动作后是否允许其他级复用确认时间必须明确，默认不复用。
- PID 的方向、限幅、采样、跟踪、抗积分饱和及工频投切后的协调须根据目标平台能力冻结。普通 30 秒
  不放进每次 PID 计算；KZ3 拥有 PID 时，KP/KI 按
  [PID 上位机整定契约](../pid-online-tuning-contract.md) 北向可调并执行改单重投，不承诺当前 API 未支持的在线 KD。
- 未整定范围可作为受禁用门禁保护的调试项；复位按本机恢复白名单处理，不清共享 PID 或共享调度阶段。独立过程重新
  开始命令只在需求需要时提供，不借复位顺带恢复自动。

## 必测输入序列

声明 `control_features: [STAGED_GROUP, HETEROGENEOUS_GROUP, PID_LOOP]`（仅选实际涉及项；厂家 PID
仍需检查控制归属，但不为未实现的 KZ3 PID 造代码）。每个场景须写真实输入、扫描时间和输出断言：

| 场景 | 最低反例 |
| --- | --- |
| STAGE_TRANSITIONS | 全部上升/下降、等号、跳级、总停及处于滞回区；只满足一个条件不加级 |
| CAPACITY_OWNERSHIP | 自动+手动+就地、启动中、停止粘连、失联；同设备不重复计数、未知不释放容量 |
| HETEROGENEOUS_REPLACEMENT | 变频泵故障、工频泵故障、无合格备用及降级恢复；仅执行采纳分支 |
| PID_OWNER | 分别核对厂家与控制器控制分支，拒绝未冻结/双重调节接口 |
| PID_TRANSFER | 实现闭环时覆盖手自动、饱和和工频投切；厂家闭环时验证本机模式/给定不干扰，真实调节待 HIL |
| PARAMETER_UPDATE | 29 秒时改变合法阈值/确认时间，旧计时不继承；非法参数禁用；分笔写入不使用非法中间组 |

另按共性门禁测试质量、回绕、故障复位、恢复及真实累计。HIL 验证物理动作、调节稳定性、容量和反应
时间；文档或模板主机测试不能替代现场验收。本卡不新增任何标准认证声明。
