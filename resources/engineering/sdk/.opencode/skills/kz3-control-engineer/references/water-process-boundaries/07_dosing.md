# W07_DOSING · 加药泵与比例投加

状态：reference_boundary；PLC 需求边界参考，非认证模板、非可运行项目。

## 原始输入形状与适用判据

PLC 初步需求示例：“按进水流量比例加药，药箱低位报警，计量泵一用一备；或依据余氯/pH 等反馈调节。”

点位证据：进水流量/脉冲、药箱液位、泵就绪/运行/故障、投加命令、药液流量证明/分析仪按原方案。脉冲频率和最小脉宽须核查当前采集能力。

匹配条件：分别匹配手动定量、流量比例、分析仪闭环、批次投加，不能互相替换。pH 与余氯的算法和工艺风险不同。

必须保留：保留药剂种类、比例单位、浓度基准、计量泵标定和 owner；仅给流量比例时不自行新增闭环或剂量优化。
