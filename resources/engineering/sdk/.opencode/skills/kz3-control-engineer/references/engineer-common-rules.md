# 从原技能继承的共性规则

这些是本产品的软件规则，不宣称是所有 PLC 的强制标准。项目明文例外必须记录并审查影响；
未知物理事实不能用规则填补。

- 一个扫描读取一次输入快照；先质量/保护、再命令/状态机、最后唯一输出仲裁。STOP 高于 START，保护停机不等普通延时。
- 每台手动、自动选择、命令、故障、复位和计时独立；共享压力/PID/调度保持唯一 owner。自动不启停手动设备。
- 远程许可 GOOD+false 只是禁止，不能合入故障。硬接故障实时 FLT、历史 F_DEV、分项汇总 F_L 分开；每台独立 RST。
- 复位只清已消除原因的本机允许项并恢复 READY，丢弃旧请求；复位与 START 同拍不启动。健康复位幂等。
- 有真实运行反馈才累计真实运行时间，使用 KZ3 runtime，不手写持久化计数。到位反馈不是运行反馈。
- 双向阀手动反向必须先独立 STOP、两方向输出全断满 2000 ms 后重新发令。未停/早到命令丢弃，不排队、
  不延后自动执行；自动先全断至少 2000 ms 后重判原条件。两方向永不同时输出，复位/模式变更不能绕过。
  开/关到位不等同互斥模板的“电机停止反馈”，不能直接将到位信号塞进 T02。
- 未给反馈时限时继承本产品默认：继电器启动 5 s、停止 30 s、运行丢失 5 s；阀开/关行程各 120 s。
  写入需求及测试并标明来自软件默认；明确项目值优先。没有反馈的设备不能套反馈监督。
- 普通工艺阈值持续确认可建议 30 s，但需记录采纳；不用于急停、超压保护等保护停机。
  2 s 反转保护不允许由未填写参数或在线值缩短。详见 [计时契约](control-timing-contract.md)。
- 使用无符号时间差，覆盖 T−1/T/T+1、晚到反馈、重复命令、回绕及长扫描。缺质量不能当已停/已到位。
- PID 只有一个 owner；KZ3 执行时 KP/KI 独立可写且运行时真正消费，改增益退出闭环并重新投入。
  厂家执行 PID 时不另建 KZ3 回路。无测量、参数非法、失去执行权时按冻结安全策略处理。
- 主机验证、协议 ACK、软件输出均不能证明现场动作或硬接线安全。引用完整约束：
  [设备归属](device-ownership-contract.md)、[复位](reset-recovery-contract.md)、[PID](pid-online-tuning-contract.md)。
